# Warden role-based access control

Sensitive capabilities are independent: campaign operation, certification decisions, application ownership, access requests, policy management, revocation execution, evidence export, audit, and tenant administration.

Reviewers can decide only their assigned items. Application owners manage their governed applications. Policy managers maintain SoD rules but cannot silently certify access. Auditors export evidence without changing the campaign. Revocation execution is never implied by ordinary reviewer access. Unknown IdP groups receive `requester`.
